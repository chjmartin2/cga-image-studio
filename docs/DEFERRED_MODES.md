# Deferred mode work

These ideas are outside the initial release candidate. This is a source-repository
backlog, not a list of supported product features or a commitment to implement them.

- **640x200 (2 Colors) Mode Switch:** removed from the selectable GUI modes.
  Existing experimental conversion code is retained for reference; DOS export
  is not implemented. Reintroduction requires complete export and validation work.
- **Additional text-based modes:** inventory and research modes not previously
  considered before deciding which offer a distinct benefit.
- **Mixed-screen modes:** research backlog; low priority per user preference.
- **Additional flicker modes:** assess separately from temporal modes already
  present in the application; document flicker and validate full frame sequences.
- **Odd-resolution modes, including prior CGA Ultimate work:** recover and review
  the earlier work before defining implementations or hardware requirements.

Do not expand release scope with these modes while qualifying the retained modes.
